Jellyfin Party

Watch parties with chat, transparent webcams, P2P calls and a WebSocket relay.

The web integration must also be installed into the Jellyfin web directory. See the installation section in the repository README.

Used to discover direct P2P connections. Leave empty for local-network P2P only, with relay fallback for remote users.

Relay video uses 480×270 JPEG at approximately 6 fps; voice uses 16 kHz mono PCM. Relay bandwidth grows with the number of connected participants. No forwarded ports are needed.
